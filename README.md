# Прототип СУО

Самостоятельный проект: только текущие экраны физических лиц, бизнеса, вложенные меню и выдача талона. Старые эксперименты и приложения сюда не включены. Все изображения и шрифты локальные, серверная часть и внешние API не нужны.

## Запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Прототип открывается сразу по корневому адресу, без `?kiosk=prototype`. Старый параметр также не мешает работе. Навигация использует hash, поэтому обновление вложенного экрана на GitHub Pages не требует серверных перенаправлений.

Размер экрана — строго 1280 × 1024, по центру на чёрном фоне. При меньшем окне доступна прокрутка, масштабирование не применяется. Интерфейс демонстрационный: реальные талоны не выдаются. Через 10 секунд после выдачи талона происходит возврат на главную.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите **содержимое этой папки в корень репозитория**, включая `.github/workflows/deploy.yml`, `.gitignore` и `package-lock.json`. Не загружайте родительский проект, `node_modules` и `dist`.
3. Используйте ветку `main` (или измените её имя в workflow).
4. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
5. После push в `main` workflow соберёт и опубликует сайт. При необходимости запустите его вручную в разделе Actions.

Сборка использует относительные пути: подойдёт адрес `https://USERNAME.github.io/REPOSITORY/`, без редактирования имени репозитория в коде.

Для локального просмотра production-сборки:

```sh
npm run build
npm run preview
```

## Файлы

- `src/components/kiosk-prototype.tsx` — экраны, переходы, печать и таймер.
- `src/components/kiosk-prototype-data.ts` — структура меню и услуги.
- `src/components/kiosk-prototype.css` — оформление прототипа.
- `src/assets/fonts` — шрифты, включаемые в сборку.
- `public/kiosk-assets` — изображения и иконки.

Брендовые материалы и шрифты МТС перенесены из исходного проекта. Перед публичной публикацией убедитесь, что у вас есть разрешение на их использование.
